# 0012. 한글은 웹 글꼴 없이 기기 글꼴로 그린다

## 맥락

디자인 원천(BSS Drive)의 글꼴은 Geist와 Instrument Serif인데 둘 다 한글이 없다. 시뮬레이션 68개는 각각 모든 것을 인라인한 단일 HTML이고, 외부 CDN 글꼴은 외부 요청 금지 때문에 쓸 수 없다.

## 결정

시뮬레이션에는 Geist 가변 글꼴 하나(약 70 KB, base64 약 93 KB)만 HTML 안에 넣고, 한글은 토큰의 `font.koreanFallback` 기기 글꼴 목록(Apple SD Gothic Neo, 맑은 고딕, Noto Sans KR 등)으로 그린다. 목록 사이트와 서랍도 같은 목록을 쓴다. 메뉴줄 워드마크 PNG는 빌드하는 컴퓨터의 한글 글꼴로 그린다.

## 버린 대안

- **한글 웹 글꼴(예: Pretendard)을 68개 HTML마다 인라인**: 한글 글꼴은 수백 KB~수 MB라 시뮬레이션마다 그만큼 커진다. 학교 와이파이와 휴대폰에서 첫 열림이 느려진다.
- **한글 웹 글꼴을 사이트에 한 번만 두고 시뮬레이션이 불러오기**: 시뮬레이션이 단일 파일로 열리지 않게 되고, 오프라인 묶음과 V1의 「다른 파일을 부르지 않음」 조건을 깬다.

## 결과

- 기기마다 한글 모양이 조금 다르다.
- 워드마크 PNG가 빌드 컴퓨터에 따라 달라져, 다른 컴퓨터에서 빌드한 결과는 바이트 단위로 같지 않다.
- 한글 웹 글꼴을 넣으려면 `font.faces`에 파일을 더하고 `koreanFallback`을 바꾸면 된다(토큰의 바꿔도 되는 기본값).
