# 0010. 학생 기록은 브라우저 저장소와 파일 내보내기만 쓴다

## 맥락

학생이 서랍에서 측정한 값을 모아 그래프를 그리고 과제에 써야 했다. 학교 PC는 여러 반이 함께 쓴다. 학교 공식 자료가 아닌 학생 제작물이라 학생 계정이나 개인정보를 받을 근거가 없다.

## 결정

기록은 각 브라우저의 `localStorage`에 시뮬레이션 id와 측정 정의 버전별로 둔다. 밖으로 나가는 길은 CSV(UTF-8 BOM)와 그래프 PNG 내려받기뿐이다. 공용 기기 문제는 「새 실험 시작」(확인 후 그 시뮬레이션 기록만 삭제)으로 푼다.

## 버린 대안

- **선생님 제출 기능(서버 + 로그인)**: 서버 운영, 계정, 개인정보 보관이 필요하고, 사이트가 정적이라는 전제(동시성·보안 문제 없음)가 깨진다.
- **세션 저장소(탭을 닫으면 사라짐)**: 새로 고치거나 탭을 다시 열면 기록이 사라져 여러 번 잰 값을 모을 수 없다.
- **「모두 초기화」에 기록도 지우기**: 학생이 조건을 바꿔 가며 잰 값을 한 표에 모을 수 없다.

## 결과

- 기기·브라우저를 바꾸면 기록이 따라가지 않는다. 브라우저 저장소를 지우면 사라진다.
- 같은 기기의 다음 사용자가 앞 사람 기록을 볼 수 있다. 「새 실험 시작」을 누르는 것은 사용자의 몫이다.
- 측정 정의를 바꾸면 버전을 올려 예전 기록을 CSV로 건넨 뒤 지워야 한다(서버에서 옮겨 줄 수 없다).
- 학생 기록·사용 통계를 모을 수 없으므로, 사이트 사용 현황은 알 수 없다.
