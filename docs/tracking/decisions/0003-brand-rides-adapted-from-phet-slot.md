# 0003. 학교 브랜드는 `adapted-from-phet` 자리를 빌려 쓴다

## 맥락

메뉴줄 로고를 글자 로고 「부산과학고」로, About 창을 학교 출처 문구로 바꿔야 했다. PhET의 브랜드 목록은 63개 고정 버전의 chipper마다 코드에 박혀 있어서, 새 브랜드 폴더 `bsshs`를 만들면 chipper가 거부한다. PhET는 제3자 빌드용으로 `adapted-from-phet` 브랜드를 공식으로 두고 있고, 이 브랜드는 업데이트 확인과 PhET 메뉴 항목이 이미 꺼져 있다.

## 결정

빌드할 때만 임시 슬롯의 `brand/adapted-from-phet/` 안 파일(Brand 필드, 로고 PNG, 시작 화면 SVG, 이미지 라이선스 기록)을 `brand/bsshs/`의 내용으로 바꿔 넣는다. chipper·joist가 보는 브랜드 이름과 실행 중 `Brand.id`는 `adapted-from-phet` 그대로이고, 화면에 보이는 것만 학교 표기다. 저장소 쪽 CLI 이름은 `--brand bsshs`다.

## 버린 대안

- **새 브랜드 폴더 + chipper 수정**: 브랜드 목록 코드가 63개 버전에서 제각각이라 버전마다 chipper를 고쳐야 하고, 빌드 도구를 고치는 것은 허용한 패치 범위(테마·학교 표기·문자열·외부 통신) 밖이다.
- **`phet` 브랜드로 빌드한 뒤 로고만 교체**: PhET 브랜드는 PhET 웹사이트 메뉴, 기부 안내, 제작진 칸, 업데이트 확인을 켠다. 「PhET」 이름과 외부 통신이 생긴다.

## 결과

- `Brand.id`를 바꾸면 joist의 로고 정렬이 달라지므로 바꿀 수 없다.
- 메뉴 버튼의 화면 낭독용 이름("PhET Menu")은 브랜드 폴더 밖(joist 문자열, babel 번역)에 있어 별도 규칙으로 「부산과학고 메뉴」로 바꾼다.
- joist가 로고를 PhET 로고 높이로 맞추므로 워드마크 PNG는 높이 96px로 그려야 한다.
- 브랜드 패치도 다른 패치처럼 빌드 뒤 되돌려지므로 PhET 브랜드 저장소는 바뀌지 않는다.
