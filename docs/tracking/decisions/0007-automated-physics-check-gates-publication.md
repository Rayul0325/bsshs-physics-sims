# 0007. 공개 조건은 자동 물리 검사이고, 선생님 확인은 표시만 바꾼다

## 맥락

기말 대비가 목적이라 시험 범위 기능을 빨리 공개해야 했다. 선생님 확인이 언제 될지는 정해지지 않았다. 그렇다고 물리 값이 틀린 서랍을 공개할 수는 없다.

## 결정

서랍 기능의 공개 조건은 자동 물리 검사(V3, 공식 계산값과 비교, 기본 상대 오차 1%) 통과다. 선생님 확인 상태는 배지 글자만 바꾸고 공개 여부와 기능 표시에 영향을 주지 않는다. 실패한 추가 기능은 공개하지 않으며, 처리는 둘로 나눈다: 새 시뮬레이션이 실패하면 물리 자체가 기능이므로 그 시뮬레이션을 통째로 공개 사이트에서 빼고 빌드 검사도 실패시킨다(제외 종류 `sim`). PhET 시뮬레이션이 실패하면 추가 기능인 수업 서랍만 빼고 서랍 없는 학교판으로 공개하며, 물리 검사는 실패로 보고한다(제외 종류 `drawer`). 허용 오차를 기본보다 넓힌 항목은 수업 내용의 「참고」 설명이 있어야 통과한다.

## 버린 대안

- **선생님 승인 뒤에만 공개**: 확인 날짜가 정해지지 않아 기말 전에 공개하지 못할 수 있다.
- **검사 없이 공개하고 선생님 확인으로만 거르기**: 틀린 값이 「선생님 확인 중」 표시만 단 채 학생에게 간다.
- **PhET 시뮬레이션도 실패하면 통째로 빼기**: PhET 물리는 검증된 것이라 실패는 대개 어댑터나 사례의 문제다. 통째로 빼면 원래 쓰던 시뮬레이션까지 사라진다.
- **PhET 시뮬레이션은 실패해도 서랍째 공개하고 보고만 하기**: 검사에 실패한 측정값·공식이 학생에게 그대로 간다.

## 결과

- 「선생님 확인 중」 상태로 공개된 기간이 있다(지금 14개 모두).
- 검사가 덮는 것은 사례에 적은 상태뿐이다. 사례 품질이 곧 공개 품질이다.
- 새 시뮬레이션 하나가 실패하면 공개 수가 68보다 작아져 전체 검증이 실패하므로, 조용히 빠진 채 배포되는 일이 없다.
- 허용 오차를 사례에 따로 적을 수 있지만(파동 간섭 4%, 반도체 리플 6%), 넓히려면 학생이 보는 「참고」 설명이 함께 있어야 한다.
- 제외는 검증 명령 안에서만 적용되므로, 전체 빌드 직후의 사이트 폴더를 그대로 배포하면 이 결정을 건너뛴다. 배포는 검증을 통과한 사이트 폴더만 한다.
- 서랍이 빠진 PhET 시뮬레이션의 목록 카드에도 확인 상태 배지가 남는다(무엇을 보여 줄지 정해지지 않음).
