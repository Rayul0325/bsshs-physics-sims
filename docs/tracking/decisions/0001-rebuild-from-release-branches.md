# 0001. PhET 공개 release 브랜치 소스를 다시 빌드한다

## 맥락

63개 시뮬레이션에 학교 디자인, 학교 글자 로고, 한국어 용어 교정을 입혀야 했다. PhET는 2026-10-09에 공개 polyrepo를 닫았고 새 monorepo는 공개하지 않는다. 남은 공개 소스는 GitHub `phetsims/<id>`의 release 브랜치뿐이고, 그 버전은 지금 PhET 사이트 버전보다 조금 옛것이다.

## 결정

각 시뮬레이션의 release 브랜치 HEAD와 그 브랜치 `dependencies.json`에 고정된 형제 저장소 SHA로 PhET 빌드 도구(chipper)를 직접 돌려 다시 빌드한다. 버전은 `data/sims.json`에 고정하고 따라가지 않는다.

## 버린 대안

- **PhET가 배포한 완성 HTML 위에 덧씌우기(CSS·스크립트 주입)**: 시뮬레이션 화면은 scenery가 캔버스/SVG로 그리므로 패널·버튼 색과 글꼴, 메뉴줄 로고, About 창 글자를 바꿀 수 없다. 완성 파일을 바이트 단위로 고치는 것은 압축된 코드라 버전마다 깨진다.
- **PhET 사이트의 최신 버전 쓰기**: 그 버전의 소스가 공개되지 않아 GPL 조건대로 고친 소스를 함께 공개할 수 없다.
- **고정 버전이 안 빌드되면 다른 버전으로 바꾸기**: 어떤 버전이 실제로 공개됐는지 추적할 수 없게 된다. 대신 멈추고 보고한다.

## 결과

- PhET 사이트보다 몇 패치 버전 옛것을 쓴다는 차이를 받아들인다.
- 빌드에 PhET 형제 저장소 수십 개의 미러(약 15 GB 캐시)와 슬롯 체크아웃, chipper 세대별 인자, 알려진 실패 두 가지의 덧대기가 필요하다.
- 비공개 PhET-iO 저장소를 받을 수 없으므로 PhET-iO 빌드와 그 기능은 만들 수 없다.
- PhET 새 버전은 사람이 손으로 반영해야 하고, 2026-10-09 이후 버전은 공개 소스가 없어 반영할 수 없다.
