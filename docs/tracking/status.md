### 만들었지만 자동으로 검증하지 않는 것

- 설정 창·키보드 도움말 창 안의 「PhET」 표기: 검사기가 두 창을 열지 않는다. 문자열 표 전체 점검으로 대신했다.
- 물리 검사 사례가 덮지 않는 화면·값: V3는 사례에 적힌 상태만 본다.
- 시간이 흐르며 생기는 화면 차이: V9는 첫 화면 다음부터 시계를 멈추고 비교한다.
- 실제 기기(태블릿, 전자칠판, iOS Safari) 터치 조작: 헤드리스 Chrome의 기기 흉내(390px, 터치)로만 확인했다.

## 남은 것 (먼저 할 순서대로)

1. **선생님 확인 받기.** 확인 담당 선생님이 14개를 보고 답하면 `npm run approve -- <id>` 또는 `npm run set-status -- <id> 수정 중 [메모]` → `npm run build-site` → `npm run verify` → 배포 → 실제 주소 확인. 오류 지적이 오면 고친 뒤 `set-status … 확인 중`. 수소 원자 모형은 수업 기록이 적어 대부분 표준 공식이므로, 확인 때 범위를 다시 맞출 가능성이 크다.
2. **시험 범위 교체를 파일 하나로 끝나게 만들기.** 필수 파일 누락 검사와 새 시뮬레이션 정의는 이제 `data/exam-scope.json`과 `sims/` 폴더를 따른다. 남은 것은 수업 내용 테스트에 직접 적힌 나머지 54개 id와 68이라는 수를 데이터에서 계산하게 바꾸는 일이다.
3. **서랍이 빠진 시뮬레이션의 카드 배지 정하기.** 물리 검사 실패로 서랍이 빠진 PhET 시뮬레이션에도 확인 배지가 남는다. 학생에게 무엇을 보여 줄지 정해야 한다.
4. **공식 탭에 계산 결과 보이기.** 지금은 변수마다 현재 값을 보여 주고, 공식의 결과(예: hf − W의 값)는 계산하지 않는다. 수업 내용 파일의 공식을 계산 가능한 식으로도 적어야 한다.
5. **오프라인 묶음.** 인터넷 없이 USB·학교 PC에서 여는 묶음. 시뮬레이션은 이미 파일 하나로 열리고 목록 페이지의 링크·썸네일·글꼴은 상대 경로다. `file://`로 연 목록 페이지가 실제로 동작하는지 확인하는 것과 묶음 형식(압축 파일, 배포 방법)을 정하는 일이 남았다.
6. **PhET 새 버전 반영.** 필요할 때만 사람이 `data/sims.json`의 브랜치·버전을 고쳐 반영한다. PhET 공개 polyrepo는 2026-10-09에 닫혀 그 이후 버전의 공개 소스는 없다.
7. **시험 범위 밖 시뮬레이션의 추가 기능, 다른 과목 확장.** 계획만 있다.
