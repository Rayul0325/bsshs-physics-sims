# bending-light 서랍 메모

- 「안내」(Intro)·「도구 추가」 화면: 위 매질 = 입사 쪽(n₁), 아래 매질 = 굴절 쪽(n₂). 각은 모델의 광선(`model.rays`, 입사·반사·굴절)의 방향과 법선(y축) 사이 각입니다. 세기는 광선의 power 비율(%)로, 세기 측정기와 같은 값입니다. 전반사이면 굴절 빛 세기는 0입니다.
- 「프리즘」 화면: 레이저가 처음 만나는 프리즘 면(`model.intersections[0]`)의 법선으로 입사각·굴절각을 잽니다. 백색광·여러 광선일 때는 비웁니다.
- 매질 속 빛의 속력은 PhET 속력계와 같은 c 단위(수업 단위 m/s 함께 표시), 매질 속 파장은 굴절된 광선의 파장입니다.
- PhET 공기의 굴절률은 1.000293이고, 굴절률은 650 nm(빨강)에서 이름 그대로(물 1.333, 유리 1.5)이며 다른 파장에서는 분산으로 조금 바뀝니다. V3 경우는 650 nm에서 계산했습니다.
