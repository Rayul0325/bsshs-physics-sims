# generator 어댑터 메모

- 시간 = 모델 시계의 단계 수 × 1/25 s. `clock.elapsedTime`은 다음 단계까지 남은 나머지라서 쓰지 않는다.
- 자석의 회전 속력 = 매 단계 자석이 실제로 돈 각도 ÷ 1/25 s(rpm, 수업 단위 rad/s). 모델에서 자석은 물 흐름 100 %에 60 rpm으로 돈다.
- 화면 rpm 계기 값(`rpmProperty`)은 코일이 만드는 끌림(최대 0.2)을 곱해 작게 나오지만, 모델의 자석 회전에는 그 끌림이 들어가지 않는다. 그래서 두 값을 따로 보여 주고, 레슨 파일 각속도 공식의 「참고」에 적었다.
- 자기 선속 = `fluxProperty`(N·Φ) ÷ N, 기전력 = `emfProperty` × 25(초 단위). 「기전력 ÷ 선속 변화율」 = −N.
- 최대 기전력은 물 흐름·자석 세기·감은 수·면적을 바꿀 때 새로 잰다. 바꾼 뒤 한 바퀴 이상 기다렸다 기록한다. 측정해 보면 감은 수에는 정확히 비례하고(1:2:4 → 1:2:4), ω에는 거의 비례한다(25 %:50 %:100 % → 1 : 1.99 : 3.89).
- V3 검사: 물을 잠그면 정지·기전력 0, 50 %면 30 rpm = π rad/s, f = 0.5 Hz, 기전력 ÷ 선속 변화율 = −2, −4, 자석 세기 0이면 돌아도 선속·기전력 0.
