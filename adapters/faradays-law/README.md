# faradays-law 어댑터 메모

- 이 시뮬레이션은 화면에 숫자가 없어서, 서랍의 자기 선속·기전력은 모두 모델 값(단위 없음)이다. 서랍 안에만 나온다.
- 자기 선속 = 아래 코일의 `magneticFieldProperty`(코일 한 바퀴를 지나는 상대 선속). 변화율과 자석의 속력은 어댑터가 매 프레임(joist가 `phet.joist.elapsedTime`에 더한 dt)마다 모델 값으로 계산한다.
- 모델의 기전력은 `(그림의 고리 수 / 2) · ΔΦ/Δt`: 감은 수 N은 아래 코일 2, 위 코일 1이고, 부호는 +이다(고리의 방향을 반대로 잡은 것, 크기는 ε = −N ΔΦ/Δt와 같다). 레슨 파일 패러데이 법칙의 「참고」에 적었다.
- 「최근 움직임의 최대 …」는 자석이 0.5 s 이상 멈췄다가 다시 움직이거나 선속이 다시 변하기 시작할 때 새로 잰다. 자석을 코일에 통과시킨 뒤 「기록」을 누르면 그 통과의 최대 속력과 최대 기전력이 남는다.
- 이 joist 판에는 `selectedScreenProperty`가 없어서 어댑터가 화면(1개)과 이름(시뮬레이션 이름)을 직접 찾는다.
- V3 검사(`cases.json`): 코일 한가운데(가까운 자기장, 선속 ±2로 포화)에서 자석을 뒤집으면 ΔΦ = 4이므로 ε = N·4/Δt. Δt를 두 배로 하면 절반, 위 코일(N = 1)은 절반, 코일 안에서 움직여 선속이 그대로면 0, 멈춰 있으면 0.
