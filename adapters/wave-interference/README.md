# wave-interference 서랍 메모

- PhET 2.0.21은 2019년 joist라 `selectedScreenProperty`가 없습니다. 그래서 `drawer.helpers.screen()`·`model()`·`screenName()`이 비어 있고, 어댑터가 `showHomeScreenProperty` + `screenIndexProperty`로 화면을 직접 찾습니다. 화면 이름은 「슬릿 · 빛」처럼 장면(물·소리·빛)까지 붙입니다.
- 길이는 모두 nm로 기록합니다(물·소리 장면의 cm 값도 nm로 바꿈). 수업 단위 m가 함께 나옵니다.
- 무늬 간격은 빛 장면에서만 나옵니다. 스크린 세기(`intensitySample.getIntensityValues()`, 격자 한 칸 = 5000/111 ≈ 45 nm)에서 가운데 밝은 무늬와 양옆 밝은 무늬를 찾아(세 점 포물선 보간) (오른쪽 − 왼쪽)/2로 잽니다. 끝 3칸과 최대의 5% 미만 봉우리는 버립니다. 무늬가 아직 안 생겼으면 비어 있습니다.
- L = 스크린 열(격자 끝에서 1.5칸 안쪽) − 장벽 열(슬릿 화면) 또는 점파원 열(간섭 화면).
- PhET는 격자 위에서 파동 방정식을 풉니다. 화면의 L이 d의 몇 배밖에 안 되므로 작은 각 근사 Lλ/d보다 5% 이상 큰 값이 나옵니다. V3 기대값은 두 슬릿까지의 경로차가 λ인 자리(정확한 기하)로 계산했고, 허용 오차 4%는 격자 해상도 때문입니다(슬릿 폭 200 nm, λ ≥ 380 nm, 장벽 위치 50·75칸에서 쓸어 본 오차는 대부분 ±3% 안). 같은 경우를 Lλ/d로 바꾸면 8~20% 어긋나 검사가 실패합니다.
- 간섭 화면은 점파원 간격이 격자 칸으로 반올림되어(2칸 단위) 오차가 조금 더 큽니다(측정 예 2.1%).
