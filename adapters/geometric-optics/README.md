# geometric-optics 서랍 메모

- 부호 규약은 PhET와 수업이 같습니다: 1/a + 1/b = 1/f, m = −b/a, 실상 b > 0, 허상 b < 0, 모으는 렌즈·오목거울 f > 0.
- 다른 점 하나: PhET 내부의 곡률반지름은 거울도 「볼록 +」입니다(화면에는 크기만 보임). 서랍의 거울 R는 수업 규약(오목 +, R = 2f)으로 바꿔 보여 줍니다.
- PhET 렌즈는 두 면이 같은 대칭 렌즈라 R₁ = R, R₂ = −R로 기록합니다. 그러면 렌즈 제작자 공식 1/f = (n − 1)(1/R₁ − 1/R₂)가 PhET의 f = R/(2(n − 1))와 같습니다.
- 물체가 초점에 있으면 PhET는 b를 무한대 대신 10⁷ cm로 둡니다.
- 물체는 「물체 1」(연필 같은 그림 물체, 화살표, 광원 중 지금 고른 것)과 그 상을 읽습니다.
