# 부산과학고 물리 시뮬레이션 (학생 제작판)

부산과학고 「전자기와 양자」 수업에서 쓰려고 만든 물리 시뮬레이션 모음입니다.

> **부산과학고 학생 제작 · 학교 공식 자료 아님**

## 구성

- PhET 물리 시뮬레이션 63개를 공개 소스로 다시 빌드하고 학교 디자인을 입힌 수정본
- 직접 설계한 시뮬레이션 5개: 광전효과, 콤프턴 산란, 레이저, 반도체·다이오드, 편광·브루스터각
- 기말 시험 범위 14개에 붙인 「수업 서랍」: 측정 기록, 그래프, 수업 공식·용어
